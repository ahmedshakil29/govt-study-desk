## Digital Electronics

### ২১. নিম্নলিখিত Boolean Function টি সংক্ষিপ্ত আকারে লিখুন: F(A,B,C,D) = A'B'C' + B'CD' + A'B'CD' + ABC'

**ব্যাখ্যা:** চার ভেরিয়েবলের function সরল করতে K-map সবচেয়ে নির্ভরযোগ্য। আগে minterm বের করে গ্রুপ করা হবে।

**সমাধান:**

**ধাপ ১: Minterm (ABCD)**

- A'B'C' (D যেকোনো) = 0000, 0001 → m0, m1
- B'CD' (A যেকোনো) = 0010, 1010 → m2, m10
- A'B'CD' = 0010 → m2 (উপরের পদে আগেই আছে)
- ABC' (D যেকোনো) = 1100, 1101 → m12, m13
- F = Σm(0, 1, 2, 10, 12, 13)

**ধাপ ২: K-map**

| AB \ CD | 00          | 01          | 11  | 10          |
| ------- | ----------- | ----------- | --- | ----------- |
| 00      | **1** (m0)  | **1** (m1)  | 0   | **1** (m2)  |
| 01      | 0           | 0           | 0   | 0           |
| 11      | **1** (m12) | **1** (m13) | 0   | 0           |
| 10      | 0           | 0           | 0   | **1** (m10) |

**ধাপ ৩: গ্রুপ**

- m0, m1 → A'B'C'
- m2, m10 → B'CD' (কোণার-সংলগ্ন নয়, কিন্তু B'=1, C=1, D'=1, A যেকোনো, তাই বৈধ গ্রুপ)
- m12, m13 → ABC'
- সব minterm এই তিন গ্রুপে ঢাকা পড়ে (m0 ও m2 অন্য গ্রুপের অন্তর্ভুক্ত)।

∴ **F = A'B'C' + B'CD' + ABC'**

**বিশ্লেষণ:** মূল রাশির ৩য় পদ A'B'CD' বাড়তি (redundant), কারণ B'CD' তাকে absorb করে (X + XY = X)।

⚠️ **নোট:** শেষ পদটির overbar ছবিতে অস্পষ্ট; আমি ABC' ধরেছি। অন্য পাঠ হলে গ্রুপ বদলাবে।

### ২২. AB'C'D + A'BD' + ABCD convert it into minimum lateral (minimal SOP).

**ব্যাখ্যা:** "Minimum lateral" বলতে সম্ভবত minimum SOP (সবচেয়ে কম পদ/literal) বোঝানো হয়েছে। দেখতে হবে কোনো দুটি পদ এক ভেরিয়েবলে ভিন্ন কি না (adjacent), হলে মেলানো যায়।

**সমাধান:**

- AB'C'D = 1001 (m9)
- A'BD' = A'BC'D' + A'BCD' = 0100, 0110 (m4, m6) → এই দুটি আগেই মিলিত (B বাদে C নেই)
- ABCD = 1111 (m15)
- m9 ও m15 পরস্পর দুই ভেরিয়েবলে ভিন্ন (B, C), m9/m15 ও m4/m6-এর সাথেও মেলে না।
- কোনো দুটি পদই adjacent নয়, তাই আর সরল হয় না।
- ∴ **AB'C'D + A'BD' + ABCD** (ইতিমধ্যেই minimal)

⚠️ **নোট:** overbar-এর অবস্থান অস্পষ্ট। আমি উপরের পাঠ ধরেছি। যদি প্রথম পদ ABC'D হতো, তাহলে ABC'D + ABCD = ABD এবং ফল ABD + A'BD' = B(AD + A'D') = **B(A ⊙ D)** (XNOR) হতো। মূল বইয়ের চিহ্ন দেখে নিশ্চিত করো।

### ২৫. Simplify the Boolean expression as possible: ABC'D' + ABCD + ABD'

**ব্যাখ্যা:** Absorption ও X + X'Y = X + Y সূত্র।

**সমাধান:**

- ABC'D' + ABD' = ABD'(C' + 1) = ABD' (absorption)
- এখন: ABD' + ABCD = AB(D' + CD)
- D' + CD = D' + C (X + X'Y = X + Y, যেখানে X = D')
- = AB(C + D') = **ABC + ABD'**

**সমাধান:**

- ABC'D' + ABCD + ABD'
- = ABD' + ABC'D' + ABCD [পদগুলো সাজানো হলো]
- = ABD'(1 + C') + ABCD [ABD' common নিয়ে]
- = ABD' + ABCD [Null Law: 1 + C' = 1]
- = AB(D' + CD) [AB common নিয়ে]
- = AB(D' + C) [Redundancy Law: x + x'y = x + y, এখানে x = D'; D' + D·C = D' + C]
- = ABC + ABD' [Distributive Law / বণ্টন সূত্র]
- ∴ **Result = AB(C + D') = ABC + ABD'** (Ans.)

**যাচাই:**

- ABC'D' পদটি ABD' দ্বারা absorbed, কারণ ABD' + ABC'D' = ABD'(1 + C') = ABD'
- যাচাই (A = B = 1 ধরে): মূল রাশি = C'D' + CD + D' = D' + CD = D' + C
- সরলীকৃত রাশি = C + D', দুটি সমান ✔

### ২৫. Simplify the Boolean expression as possible: AB'C'D + ABCD + AB'D'

**ব্যাখ্যা:** এখানে কোনো পদই অন্য পদকে absorb করে না, তাই আগে minterm বের করে K-map-এ গ্রুপ করা সবচেয়ে নিরাপদ। AB'D' পদে C নেই, তাই সেটি দুটি minterm নিয়ে গঠিত।

**সমাধান:**

**ধাপ ১: Minterm (ABCD)**

- AB'C'D = 1001 → m9
- ABCD = 1111 → m15
- AB'D' (C যেকোনো) = 1000, 1010 → m8, m10
- F = Σm(8, 9, 10, 15)

**ধাপ ২: K-map**

| AB \ CD | 00         | 01         | 11          | 10          |
| ------- | ---------- | ---------- | ----------- | ----------- |
| 00      | 0          | 0          | 0           | 0           |
| 01      | 0          | 0          | 0           | 0           |
| 11      | 0          | 0          | **1** (m15) | 0           |
| 10      | **1** (m8) | **1** (m9) | 0           | **1** (m10) |

**ধাপ ৩: গ্রুপ**

- **Pair ১:** m8, m9 → AB'C' (A=1, B=0, C=0 স্থির; D পরিবর্তনশীল)
- **Pair ২:** m8, m10 → AB'D' (A=1, B=0, D=0 স্থির; C পরিবর্তনশীল)
- **Single:** m15 → ABCD (এর কোনো adjacent cell (m7, m11, m13, m14) 1 নয়, তাই একা)
- m9 শুধু Pair ১-এ এবং m10 শুধু Pair ২-এ আছে, তাই দুটি pair-ই essential।

∴ **F = AB'C' + AB'D' + ABCD**

**বিশ্লেষণ (বীজগণিতীয় যাচাই):**

- AB'C'D + AB'D' = AB'(C'D + D')
- C'D + D' = C' + D' (Redundancy Law: x + x'y = x + y, এখানে x = D')
- ∴ AB'C'D + AB'D' = AB'(C' + D') = AB'C' + AB'D'
- ABCD অন্য কোনো পদের সাথে মেলে না, তাই অপরিবর্তিত থাকে।
- ∴ **F = AB'(C' + D') + ABCD = AB'C' + AB'D' + ABCD** (Ans.)

**বিকল্প আকার:** AB'(C' + D') = AB'(CD)' (De Morgan), তাই
F = A[B'(CD)' + B(CD)] = **A·(B ⊙ CD)** (XNOR আকারে)। Literal সংখ্যা ১১ থেকে কমে SOP-তে ১০টি হলো।

### ২৮. Draw a truth table that satisfies the above-mentioned equation: Y = A'B'C'D' + A'B'C + A'BC' + A'BCD [38th BCS]

**ব্যাখ্যা:** চার ভেরিয়েবলে ২⁴ = ১৬টি সারি। যে সারি কোনো পদকে সত্য করে, সেখানে Y = 1।

**সমাধান:**

- A'B'C → 0010, 0011 (m2, m3)

⚠️ **নোট:** শেষ পদে (A'BCD) overbar-এর পাঠ অস্পষ্ট। আমি A'BCD ধরেছি। অন্য পাঠে সারি বদলাবে।

### ৫৫. Simplify the following Boolean function using K-map: Y = ABCD + ABC'D' + A'BCD' + A'BCD + ABCD + AB'C'D' + ABC + ABCD [BPSC AP 2023]

**ব্যাখ্যা:** আগে প্রতিটি পদকে minterm-এ রূপান্তর করে K-map-এ বসাতে হবে। যে পদে ভেরিয়েবল কম, তা একাধিক minterm বোঝায়।

⚠️ **নোট:** ছবিতে overbar অস্পষ্ট, তাই আমি পদগুলো এভাবে পড়েছি: ABCD, ABC'D', A'BCD', A'BCD, ABCD, AB'C'D', ABC, ABCD। ভিন্ন পাঠ হলে উত্তর বদলাবে।

**সমাধান:**

**Minterm (ABCD):**

- ABCD = 1111 (m15)
- ABC'D' = 1100 (m12)
- A'BCD' = 0110 (m6)
- A'BCD = 0111 (m7)
- AB'C'D' = 1000 (m8)
- ABC = 1110, 1111 (m14, m15)
- Y = Σm(6, 7, 8, 12, 14, 15)

**K-map:**

| AB \ CD | 00          | 01      | 11          | 10          |
| ------- | ----------- | ------- | ----------- | ----------- |
| 00      | 0           | 0       | 0           | 0           |
| 01      | 0 (m4)      | 0 (m5)  | **1** (m7)  | **1** (m6)  |
| 11      | **1** (m12) | 0 (m13) | **1** (m15) | **1** (m14) |
| 10      | **1** (m8)  | 0 (m9)  | 0 (m11)     | 0 (m10)     |

**গ্রুপ:**

- **Quad:** m6, m7, m14, m15 → B = 1, C = 1 → **BC**
- **Pair:** m8, m12 → A = 1, C = 0, D = 0 → **AC'D'**

∴ **Y = BC + AC'D'**

### ৬০. F = A'B'C' + AB'C' + A'B'C + A'BC + ABC, Simplify using K-map with logic circuit. [JBL, SO (ANE) 2020]

**ব্যাখ্যা:** ৩ ভেরিয়েবলের K-map (৮টি ঘর) ব্যবহার হবে।

⚠️ **নোট:** ছবিতে overbar অস্পষ্ট; আমি পদগুলো এভাবে পড়েছি: A'B'C', AB'C', A'B'C, A'BC, ABC। ভিন্ন পাঠ হলে মূল বই দেখে মিলিয়ে নিও।

**সমাধান:**

**Minterm (ABC):** 000 (m0), 100 (m4), 001 (m1), 011 (m3), 111 (m7) → F = Σm(0, 1, 3, 4, 7)

**K-map:**

| A \ BC | 00         | 01         | 11         | 10     |
| ------ | ---------- | ---------- | ---------- | ------ |
| 0      | **1** (m0) | **1** (m1) | **1** (m3) | 0 (m2) |
| 1      | **1** (m4) | 0 (m5)     | **1** (m7) | 0 (m6) |

**গ্রুপ:**

- m0, m4 → B = 0, C = 0 → **B'C'** (প্রয়োজনীয়, কারণ m4 শুধু এখানে)
- m3, m7 → B = 1, C = 1 → **BC** (প্রয়োজনীয়, কারণ m7 শুধু এখানে)
- বাকি m1: দুই উপায়ে ঢাকা যায়: m0, m1 → **A'B'** অথবা m1, m3 → **A'C**

∴ **F = B'C' + BC + A'B'**
অথবা **F = B'C' + BC + A'C**

(দুটি উত্তরই সমান সংক্ষিপ্ত ও সঠিক। B'C' + BC = (B ⊙ C) XNOR)

**Logic circuit (প্রথম রূপ, F = B'C' + BC + A'B'):**

```
B ──NOT── B' ──┐
C ──NOT── C' ──AND── x1 ──┐
B ──────────────┐         │
C ──────────────AND── x2 ─┤
A ──NOT── A' ──┐          OR3 ── F
B' ────────────AND── x3 ──┘
```

Gate: ৩টি NOT (A', B', C'), ৩টি 2-input AND, ১টি 3-input OR।

### ৬১. Simplify the equation by using K-map: f(A,B,C) = A'B'C' + A'BC + A'B'C + ABC [38th BCS]

**ব্যাখ্যা:** ৩ ভেরিয়েবলের K-map ব্যবহার হবে।

⚠️ **নোট:** overbar-এর পাঠ ছবিতে অস্পষ্ট; আমি পদগুলো এভাবে পড়েছি: A'B'C', A'BC, A'B'C, ABC।

**সমাধান:**

**Minterm (ABC):** 000 (m0), 011 (m3), 001 (m1), 111 (m7) → f = Σm(0, 1, 3, 7)

**K-map:**

| A \ BC | 00         | 01         | 11         | 10     |
| ------ | ---------- | ---------- | ---------- | ------ |
| 0      | **1** (m0) | **1** (m1) | **1** (m3) | 0 (m2) |
| 1      | 0 (m4)     | 0 (m5)     | **1** (m7) | 0 (m6) |

**গ্রুপ:**

- m0, m1 → A = 0, B = 0 → **A'B'** (প্রয়োজনীয়, কারণ m0 শুধু এখানে)
- m3, m7 → B = 1, C = 1 → **BC** (প্রয়োজনীয়, কারণ m7 শুধু এখানে)
- (m1, m3 → A'C একটি অতিরিক্ত গ্রুপ হতে পারে, কিন্তু m1 ও m3 আগেই ঢাকা, তাই redundant)

∴ **f = A'B' + BC**

**যাচাই:** 000 → A'B' = 1 ✓; 001 → A'B' = 1 ✓; 011 → BC = 1 ✓; 111 → BC = 1 ✓; 010 → A'B' = 0, BC = 0 → 0 ✓।
