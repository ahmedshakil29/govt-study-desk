### ৮১. একটি ঘনকের সম্পূর্ণ পৃষ্ঠের ক্ষেত্রফল ৪৮ বর্গমিটার। ঘনকটির কর্ণের দৈর্ঘ্য কত?

- ক. 2√2 মিটার
- খ. 2√3 মিটার
- গ. 2 মিটার
- **ঘ. 2√6 মিটার** ✅

**ব্যাখ্যা:**

- **সূত্র:** ঘনকের সম্পূর্ণ পৃষ্ঠের ক্ষেত্রফল = 6a²; ঘনকের কর্ণ (দেহকর্ণ) = a√3 (a = এক বাহুর দৈর্ঘ্য)।
- **ধাপ ১:** 6a² = 48 ⇒ a² = 8 ⇒ a = √8 = 2√2 মিটার।
- **ধাপ ২:** কর্ণ = a√3 = 2√2 × √3 = 2√6 মিটার।
- **যাচাই:** কর্ণ² = 3a² = 24, তাই কর্ণ = √24 = 2√6 ≈ 4.899 মিটার।

**ভুল অপশন:** 2√2 হলো বাহুর দৈর্ঘ্য (কর্ণ নয়)। 2√3 পাওয়া যায় a = 2 ধরলে (তখন পৃষ্ঠতল হতো 24, ৪৮ নয়)। "2 মিটার" কর্ণ হতে পারে না, কারণ কর্ণ সব সময় বাহুর √3 গুণ।

### ৮২. একটা লোহার গোলক গলিয়ে কয়টি সমান আয়তনের গোলক তৈরি সম্ভব, যাদের প্রত্যেকের ব্যাসার্ধ বড় গোলকটির অর্ধেক?

- ক. ৪
- **খ. ৮** ✅
- গ. ১৬
- ঘ. ২

**ব্যাখ্যা:**

- **সূত্র:** গোলকের আয়তন V = (4/3)πr³। গলিয়ে নতুন গোলক বানালে মোট আয়তন অপরিবর্তিত থাকে।
- **ধাপ ১:** বড় গোলকের ব্যাসার্ধ R, ছোটগুলোর r = R/2।
- **ধাপ ২:** ছোট গোলকের আয়তন = (4/3)π(R/2)³ = (1/8) × (4/3)πR³।
- **ধাপ ৩:** সংখ্যা = (4/3)πR³ ÷ [(1/8) × (4/3)πR³] = **৮টি**।
- **শর্টকাট:** ব্যাসার্ধ k গুণ হলে আয়তন k³ গুণ। k = 1/2 হলে আয়তন 1/8 গুণ, তাই সংখ্যা 8।
- **ভুল অপশন:** ৪ বা ২ পাওয়া যায় ব্যাসার্ধ বা ক্ষেত্রফলের অনুপাত ধরলে (ক্ষেত্রফল 1/4 গুণ হয়), কিন্তু সংখ্যা নির্ধারণ হয় **আয়তনে**। ১৬ ভুল, কারণ (1/2)³ = 1/8, 1/16 নয়।

### ৮৩. log_x 4 = −2 হলে x = কত?

- **ক. 1/2** ✅
- খ. −1/2
- গ. 2
- ঘ. −2

**ব্যাখ্যা:**

- **সূত্র:** log_a b = c হলে b = a^c, এবং লগের ভিত্তি a অবশ্যই **ধনাত্মক ও 1 নয়** (a > 0, a ≠ 1)।
- **ধাপ ১:** log_x 4 = −2 ⇒ 4 = x^(−2) = 1/x²।
- **ধাপ ২:** x² = 1/4 ⇒ x = ±1/2।
- **ধাপ ৩:** ভিত্তি ঋণাত্মক হতে পারে না, তাই x = −1/2 বাদ। **x = 1/2**।
- **যাচাই:** (1/2)^(−2) = 2² = 4 ✓।
- **ভুল অপশন:** −1/2 ও −2 ঋণাত্মক ভিত্তি, লগের জন্য অগ্রহণযোগ্য। x = 2 হলে log_2 4 = **+2**, −2 নয়।

### ৮৪. একটি ত্রিভুজের প্রথম কোণ দ্বিতীয় কোণের অর্ধেক। তৃতীয় কোণ অপর দুই কোণের বিয়োগফলের তিনগুণ। দ্বিতীয় কোণটি কত ডিগ্রী?

- ক. ৩০
- **খ. ৬০** ✅
- গ. ৯০
- ঘ. ৪৫

**ব্যাখ্যা:**

- **সূত্র:** ত্রিভুজের তিন কোণের সমষ্টি = 180°।
- **ধাপ ১:** দ্বিতীয় কোণ = x; প্রথম কোণ = x/2।
- **ধাপ ২:** অপর দুই কোণের বিয়োগফল = x − x/2 = x/2; তৃতীয় কোণ = 3 × (x/2) = 3x/2।
- **ধাপ ৩:** x/2 + x + 3x/2 = 180° ⇒ 3x = 180° ⇒ **x = 60°**।
- **যাচাই:** কোণ তিনটি 30°, 60°, 90°; যোগফল 180° ✓; তৃতীয় কোণ 90° = 3 × (60° − 30°) ✓।
- **ভুল অপশন:** ৩০° হলো **প্রথম** কোণ, ৯০° হলো **তৃতীয়** কোণ (প্রশ্নে দ্বিতীয় কোণ চাওয়া হয়েছে)। ৪৫° ধরলে কোণ তিনটি 22.5°, 45°, 67.5° হয় এবং তৃতীয় কোণ শর্ত (3 × 22.5° = 67.5°) মিললেও যোগফল 135° হয়, 180° নয়।

### ৮৫. একটি সমান্তর ধারার ৪র্থ (চতুর্থ) এবং ১২তম পদের যোগফল ২০। ঐ ধারার প্রথম ১৫ পদের যোগফল কত?

- ক. ১০০
- **খ. ১৫০** ✅
- গ. ২০০
- ঘ. ৩০০

**ব্যাখ্যা:**

- **সূত্র:** n-তম পদ = a + (n − 1)d; প্রথম n পদের যোগফল S_n = (n/2){2a + (n − 1)d}।
- **ধাপ ১:** ৪র্থ পদ = a + 3d, ১২তম পদ = a + 11d। যোগফল 20 ⇒ 2a + 14d = 20।
- **ধাপ ২:** S₁₅ = (15/2){2a + 14d} = (15/2) × 20 = **150**।
- **শর্টকাট:** সমান্তর ধারায় মধ্যবর্তী পদ হলো দুই প্রান্তীয় পদের গড়। ৪র্থ ও ১২তম পদের গড় = ১০ = ৮ম পদ, আর ১৫ পদের ধারার মাঝের পদ ৮ম। তাই S₁₅ = ১৫ × ১০ = ১৫০।
- **ভুল অপশন:** 2a + 14d = 20 সরাসরি S₁₅ সূত্রে বসালে একটি মানই (150) আসে। ১০০, ২০০, ৩০০ সূত্রের কোনো ধাপে মেলে না (সাধারণত ১৫ বা ২ দিয়ে গুণ-ভাগে ভুলের ফল)।

### ৮৬. x² + 6x − 27 < 0 অসমতাটির সমাধান সেট নিচের কোনটি?

- ক. [−9, 3]
- খ. [3, ∞)
- **গ. (−9, 3)** ✅
- ঘ. (∞, −9)

**ব্যাখ্যা:**

- **কৌশল:** দ্বিঘাত রাশিকে উৎপাদকে ভেঙে মূল বের করি। x² এর সহগ ধনাত্মক হলে রাশিটি দুই মূলের **মাঝখানে ঋণাত্মক**, বাইরে ধনাত্মক।
- **ধাপ ১:** x² + 6x − 27 = x² + 9x − 3x − 27 = x(x + 9) − 3(x + 9) = (x + 9)(x − 3)।
- **ধাপ ২:** মূল x = −9 ও x = 3।
- **ধাপ ৩:** (x + 9)(x − 3) < 0 হবে যখন −9 < x < 3।
- **যাচাই:** x = 0 → −27 < 0 ✓; x = −10 → 13 > 0 ✗; x = 4 → 13 > 0 ✗।
- **ভুল অপশন:** "ক" বন্ধ ইন্টারভ্যালে x = −9 ও 3 ধরেছে, সেখানে রাশির মান 0, অথচ অসমতা কঠোর (< 0)। "খ" ধনাত্মক অঞ্চল (x ≥ 3 এ রাশি ≥ 0)। "ঘ" (∞, −9) নোটেশন ভুল, আর x < −9 অঞ্চলেও রাশি ধনাত্মক।

### ৮৭. একটা বাক্সে ৪টা লাল, ৩টা নীল, ২টা হলুদ ও ১টা সবুজ বল আছে। কমপক্ষে কয়টা বল উঠালে সেখানে অন্তত একটা লাল বল থাকবেই?

- ক. ৫
- খ. ৬
- **গ. ৭** ✅
- ঘ. ৮

**ব্যাখ্যা:**

- **ধাপ ১:** লাল নয় এমন বল = ৩ (নীল) + ২ (হলুদ) + ১ (সবুজ) = ৬টি।
- **ধাপ ২:** সবচেয়ে দুর্ভাগ্যজনক ক্ষেত্রে প্রথম ৬টি বলই লাল ছাড়া হতে পারে।

### ৮৮. যদি M = {a, b, 1, 2} এবং N = {1, 2} হয়, তবে N − M এর মান কত?

- **ক. { }** ✅
- খ. {a, b}
- গ. {0}
- ঘ. {−a, −b}

**ব্যাখ্যা:**

- **সংজ্ঞা:** N − M = N-এর সেসব উপাদান, যেগুলো M-এ **নেই**।
- **ধাপ ১:** N-এর উপাদান 1 ও 2; দুটিই M-এ আছে।
- **ধাপ ২:** N-এর এমন কোনো উপাদান নেই যা M-এ অনুপস্থিত, তাই N − M = ∅ বা { }। (N ⊂ M হওয়ায় N − M সব সময় ফাঁকা সেট।)
- **ভুল অপশন:** {a, b} হলো **M − N** (ক্রম উল্টো করলে)। {0} একটি সেট যাতে একটি উপাদান 0 আছে, ফাঁকা সেট নয়। {−a, −b} এর কোনো যুক্তি নেই।

### ৮৯. ax + by = a²; bx − ay = ab; এই সহ-সমীকরণের (x, y) এর সমাধান কোনটি?

- ক. (a², b²)
- খ. (a, b)
- গ. (0, a)
- **ঘ. (a, 0)** ✅

**ব্যাখ্যা:** (ধরা হলো a ও b একসঙ্গে শূন্য নয়, a² + b² ≠ 0)

- **ধাপ ১:** (1) ax + by = a²; (2) bx − ay = ab।
- **ধাপ ২:** (1) × b ⇒ abx + b²y = a²b ...(3); (2) × a ⇒ abx − a²y = a²b ...(4)।
- **ধাপ ৩:** (3) − (4): (b² + a²)y = 0 ⇒ **y = 0**।
- **ধাপ ৪:** (1)-এ y = 0 বসিয়ে ax = a² ⇒ **x = a** (a ≠ 0)।
- **যাচাই:** (2): b·a − a·0 = ab ✓।

### ৯২. দুইটি সংখ্যার ল.সা.গু 4x³ + 12x² − 16x − 48, গ.সা.গু 2x + 4। একটি সংখ্যা 4x² + 20x + 24 হলে অপরটি—

- ক. x² − 4
- **খ. 2(x² − 4)** ✅
- গ. 4(x² − 4)
- ঘ. x + 2

**ব্যাখ্যা:**

- ⚠️ **মুদ্রণ-ত্রুটি:** PDF-এর প্রশ্নে ল.সা.গু ছাপা আছে "4x² + 12x² − 16x − 48"। সঠিক রাশি **4x³ + 12x² − 16x − 48** (PDF-এর ব্যাখ্যাও তাই ধরেছে)। ছাপা রাশি (16x² − 16x − 48) ধরলে তা গ.সা.গু 2x + 4 দিয়ে বিভাজ্য হয় না (x = −2 বসালে 48 ≠ 0), যা ল.সা.গু-র শর্তের সঙ্গে সাংঘর্ষিক।
- **সূত্র:** দুই সংখ্যার গুণফল = ল.সা.গু × গ.সা.গু।
- **ধাপ ১ (উৎপাদকে বিশ্লেষণ):**
  - গ.সা.গু = 2x + 4 = 2(x + 2)
  - প্রদত্ত সংখ্যা = 4x² + 20x + 24 = 4(x² + 5x + 6) = 4(x + 2)(x + 3)
  - ল.সা.গু = 4x³ + 12x² − 16x − 48 = 4(x³ + 3x² − 4x − 12) = 4(x + 3)(x² − 4) = 4(x + 3)(x − 2)(x + 2)
- **ধাপ ২:** অপর সংখ্যা = (ল.সা.গু × গ.সা.গু) ÷ প্রদত্ত সংখ্যা = [4(x + 3)(x − 2)(x + 2) × 2(x + 2)] ÷ [4(x + 2)(x + 3)] = 2(x − 2)(x + 2) = **2(x² − 4)**।
- **যাচাই:** সংখ্যা দুটি 4(x + 2)(x + 3) ও 2(x − 2)(x + 2)। গ.সা.গু = 2(x + 2) ✓; ল.সা.গু = 4(x + 3)(x − 2)(x + 2) ✓ (কোডেও মিলিয়েছি)।
- **ভুল অপশন:** x² − 4 সঠিক উত্তরের অর্ধেক; 4(x² − 4) দ্বিগুণ। উভয়ের গ.সা.গু 2(x + 2) হয় না বা ল.সা.গু মেলে না। x + 2 কেবল একটি সাধারণ উৎপাদক, সম্পূর্ণ সংখ্যা নয়।

- **সাধারণ নিয়ম:** ভারী ওজন অবলম্বনের কাছে (ছোট বাহু) থাকে। এখানে ১৫ কেজি (বেশি) ছোট বাহুতে (৬ মিটার), ১০ কেজি (কম) বড় বাহুতে (৯ মিটার)।

### ৯৯. একটি থলিতে ৩ টি সবুজ এবং ২ টি লাল বল আছে। অপর একটি থলিতে ২ টি সবুজ এবং ৫ টি লাল বল আছে। নিরপেক্ষভাবে প্রত্যেক থলি থেকে একটি করে বল তোলা হল। দুইটি বলের মধ্যে অন্তত একটি সবুজ হওয়ার সম্ভাব্যতা কত?

- **ক. 5/7** ✅
- খ. 2/7
- গ. 5/12
- ঘ. 1/4

**ব্যাখ্যা:**

- **সূত্র (পূরক সম্ভাব্যতা):** P(অন্তত একটি সবুজ) = 1 − P(দুটিই লাল)। দুই থলি থেকে বল তোলা **স্বাধীন ঘটনা**, তাই সম্ভাব্যতা গুণ করা যায়।
- **ধাপ ১:** ১ম থলিতে মোট ৫টি বল, লাল ২টি ⇒ P(লাল) = 2/5।
- **ধাপ ২:** ২য় থলিতে মোট ৭টি বল, লাল ৫টি ⇒ P(লাল) = 5/7।
- **ধাপ ৩:** P(দুটিই লাল) = (2/5) × (5/7) = 2/7।
- **ধাপ ৪:** P(অন্তত একটি সবুজ) = 1 − 2/7 = **5/7**।
- **ভুল অপশন:** 2/7 হলো "দুটিই লাল" হওয়ার সম্ভাব্যতা (পূরক)। 5/12 হয় ৫টি সবুজ বল ÷ (৫ + ৭) ধরে দুই থলিকে একসঙ্গে মেলালে (প্রশ্নের শর্ত মেলে না)। 1/4 কোনো ধাপে আসে না।

### ১০০. PQR ত্রিভুজের ∠Q = 90° এবং ∠P = 2∠R হলে নিচের কোনটি সঠিক?

- ক. PR = 2QR
- খ. PQ = 2PR
- **গ. PR = 2PQ** ✅
- ঘ. QR = 2PQ

**ব্যাখ্যা:**

- **সূত্র:** ত্রিভুজের তিন কোণের সমষ্টি 180°; সমকোণী ত্রিভুজে সমকোণের বিপরীত বাহু অতিভুজ।
- **ধাপ ১:** ∠Q = 90° ⇒ ∠P + ∠R = 90°। ∠P = 2∠R হলে 3∠R = 90° ⇒ ∠R = 30°, ∠P = 60°।
- **ধাপ ২:** অতিভুজ = PR (∠Q-এর বিপরীত)। ∠R = 30°-এর বিপরীত বাহু PQ। সূত্র: sin R = PQ/PR ⇒ sin 30° = 1/2 = PQ/PR ⇒ **PR = 2PQ**।
- **30°-60°-90° ত্রিভুজের নিয়ম:** বাহুর অনুপাত PQ : QR : PR = 1 : √3 : 2। ছোট বাহু = অতিভুজের অর্ধেক।
- **ভুল অপশন:** PR = 2QR ভুল, কারণ QR = (√3/2)PR। PQ = 2PR অসম্ভব, কারণ সমকোণী ত্রিভুজে কোনো বাহু অতিভুজের চেয়ে বড় হতে পারে না। QR = 2PQ ভুল, কারণ QR = √3·PQ ≈ 1.73·PQ।
