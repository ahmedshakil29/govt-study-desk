# অংশ ২: অধ্যায় ১১–২০

## ১১. বীজগাণিতিক সূত্রাবলী

**মূল সূত্র (মুখস্থ):**

- (a+b)² = a² + 2ab + b²
- (a−b)² = a² − 2ab + b²
- a² − b² = (a+b)(a−b)
- (a+b)² − (a−b)² = 4ab; (a+b)² + (a−b)² = 2(a² + b²)
- (a+b)³ = a³ + b³ + 3ab(a+b)
- (a−b)³ = a³ − b³ − 3ab(a−b)
- a³ + b³ = (a+b)(a² − ab + b²)
- a³ − b³ = (a−b)(a² + ab + b²)
- (a+b+c)² = a² + b² + c² + 2(ab + bc + ca)
- a³ + b³ + c³ − 3abc = (a+b+c)(a² + b² + c² − ab − bc − ca)
- **a + b + c = 0 হলে a³ + b³ + c³ = 3abc**

**x + 1/x = k ধরনের অঙ্কের কৌশল:**

- x² + 1/x² = k² − 2
- x³ + 1/x³ = k³ − 3k
- x − 1/x = k হলে x² + 1/x² = k² + 2

**উদাহরণ ১:** a + b = 5, ab = 6 হলে a² + b²? (a+b)² − 2ab = 25 − 12 = **13**।

**উদাহরণ ২:** x + 1/x = 3 হলে x² + 1/x² ও x³ + 1/x³? 9 − 2 = **7**; 27 − 9 = **18**।

**উদাহরণ ৩:** 103² কত? (100+3)² = 10000 + 600 + 9 = **10609**। 98 × 102 = 100² − 2² = **9996**।

**উদাহরণ ৪:** a − b = 2, ab = 15 হলে a³ − b³? (a−b)³ + 3ab(a−b) = 8 + 90 = **98**।

**উদাহরণ ৫:** x − 1/x = 4 হলে x² + 1/x²? 16 + 2 = **18**।

## ১২. উৎপাদকে বিশ্লেষণ

**চার পদ্ধতি:** ১) সাধারণ উৎপাদক বের করা, ২) সূত্র বসানো, ৩) মধ্যপদ বিভাজন, ৪) উৎপাদক উপপাদ্য।

**মধ্যপদ বিভাজন:** ax² + bx + c এ গুণফল = ac, যোগফল = b এমন দুটি সংখ্যা খুঁজে মাঝের পদ ভাঙুন।

**উদাহরণ ১:** x² − 5x + 6 গুণ 6, যোগ −5 → −2 ও −3। উত্তর: **(x−2)(x−3)**।

**উদাহরণ ২:** 2x² + 7x + 3 ac = 6, b = 7 → 1 ও 6। 2x² + 6x + x + 3 = 2x(x+3) + 1(x+3) = **(x+3)(2x+1)**।

**উদাহরণ ৩:** x⁴ − 16 = (x²+4)(x²−4) = **(x²+4)(x+2)(x−2)**।

**উদাহরণ ৪:** x³ − 8 = **(x−2)(x² + 2x + 4)**।

**উদাহরণ ৫:** a² + 2ab + b² − c² = (a+b)² − c² = **(a+b+c)(a+b−c)**।

**উৎপাদক উপপাদ্য ও ভাগশেষ উপপাদ্য:**

- f(a) = 0 হলে (x − a), f(x) এর একটি উৎপাদক।
- f(x) কে (x − a) দিয়ে ভাগ করলে **ভাগশেষ = f(a)**।

**উদাহরণ ৬:** x³ − 6x² + 11x − 6 কে উৎপাদকে বিশ্লেষণ। x = 1 বসালে 1 − 6 + 11 − 6 = 0, তাই (x−1) উৎপাদক। ভাগ করলে x² − 5x + 6 = (x−2)(x−3)। উত্তর: **(x−1)(x−2)(x−3)**।

**উদাহরণ ৭:** x² + kx + 6 কে (x−2) দিয়ে নিঃশেষে বিভাজ্য হলে k? f(2) = 4 + 2k + 6 = 0 → **k = −5**।

**উদাহরণ ৮:** x³ + 2x² − 5x + 1 কে (x−1) দিয়ে ভাগ করলে ভাগশেষ? f(1) = 1 + 2 − 5 + 1 = **−1**।

## ১৩. সূচক

**সূত্র:**

- a^m × a^n = a^(m+n); a^m ÷ a^n = a^(m−n)
- (a^m)^n = a^(mn); (ab)^n = a^n × b^n
- a⁰ = 1; a^(−n) = 1/a^n
- a^(1/n) = n-তম মূল (ⁿ√a); a^(m/n) = (ⁿ√a)^m

**সমীকরণের কৌশল:**

- **ভিত্তি সমান করুন**, তারপর সূচক সমান করুন: a^x = a^y হলে x = y।
- a^x = b^x (x ≠ 0) হলে a = b।
- সূচকে x থাকলে সাধারণ উৎপাদক নিন: 2^(x+2) = 2^x × 4।

**উদাহরণ ১:** 2^x = 32 → 2^x = 2⁵ → **x = 5**।

**উদাহরণ ২:** 3^(x+1) = 81 → x + 1 = 4 → **x = 3**।

**উদাহরণ ৩:** 2^(x+2) − 2^x = 24 2^x (4 − 1) = 24 → 2^x = 8 → **x = 3**।

**উদাহরণ ৪:** 8^(2/3) = (2³)^(2/3) = 2² = **4**।

**উদাহরণ ৫:** 5^x = 1/125 = 5^(−3) → **x = −3**।

**উদাহরণ ৬:** (2^(n+1) + 2^n) ÷ (2^(n+1) − 2^n) = 2^n × 3 ÷ (2^n × 1) = **3**।

**উদাহরণ ৭:** (1/4)^(−2) = 4² = **16**।

## ১৪. লগারিদম

**সংজ্ঞা:** a^x = N হলে log_a N = x (শর্ত: a > 0, a ≠ 1, N > 0)।

**সূত্র:**

- log_a 1 = 0; log_a a = 1
- log(MN) = log M + log N
- log(M/N) = log M − log N
- log(M^n) = n × log M
- **ভিত্তি পরিবর্তন:** log_a b = (log_c b) ÷ (log_c a)
- log_a b × log_b a = 1; log_a b × log_b c = log_a c
- a^(log_a N) = N

**মুখস্থ মান (ভিত্তি 10):** log 2 ≈ 0.3010, log 3 ≈ 0.4771, log 5 ≈ 0.6990।

**অঙ্ক সংখ্যা বের করার নিয়ম:** log₁₀ N এর পূর্ণ অংশ (**পূর্ণক**) + 1 = N এর অঙ্ক সংখ্যা।

**উদাহরণ ১:** log₂ 32 = **5**; log₃ 81 = **4**।

**উদাহরণ ২:** log 8 + log 125 = log 1000 = **3** (ভিত্তি 10)।

**উদাহরণ ৩:** log_x 64 = 3 → x³ = 64 → **x = 4**।

**উদাহরণ ৪:** log₂ (x+1) = 3 → x + 1 = 8 → **x = 7**।

**উদাহরণ ৫:** 2^50 এ কয়টি অঙ্ক? 50 × 0.3010 = 15.05, পূর্ণক 15, তাই **16টি অঙ্ক**।

**উদাহরণ ৬:** log₂ 3 × log₃ 4 = log₂ 4 = **2**।

**উদাহরণ ৭:** log x + log (x−3) = 1 (ভিত্তি 10) x(x−3) = 10 → x² − 3x − 10 = 0 → x = 5 অথবা −2। লগ কেবল ধনাত্মক সংখ্যার হয়, তাই −2 বাদ। উত্তর **x = 5**।

## ১৫. অনুপাত / সমীকরণ

অনুপাতের নিয়ম অধ্যায় ৫-এ আছে। এখানে সমীকরণ সমাধানের নিয়ম।

**একঘাত সমীকরণ:** ax + b = 0 → x = −b/a।

**দুই চলকের সহ-সমীকরণ:** প্রতিস্থাপন অথবা অপনয়ন (একটি চলক বাদ দেওয়া)।

**উদাহরণ ১:** x + y = 10, x − y = 4 → যোগ করলে 2x = 14 → **x = 7, y = 3**।

**উদাহরণ ২:** 2x + 3y = 12 এবং 3x − y = 7 দ্বিতীয়টি ×3 করলে 9x − 3y = 21। যোগ করলে 11x = 33 → x = 3, তাই y = 2। উত্তর **x = 3, y = 2**।

**দ্বিঘাত সমীকরণ** ax² + bx + c = 0:

- সূত্র: x = \[−b ± √(b² − 4ac)\] ÷ 2a
- নিশ্চায়ক D = b² − 4ac: D > 0 হলে দুটি ভিন্ন বাস্তব মূল, D = 0 হলে সমান মূল, D < 0 হলে বাস্তব মূল নেই।
- মূল α, β হলে **α + β = −b/a**, **αβ = c/a**
- α² + β² = (α+β)² − 2αβ

**উদাহরণ ৩:** x² − 5x + 6 = 0 এর মূলদ্বয়ের যোগ 5, গুণ 6।

**উদাহরণ ৪:** x² + kx + 9 = 0 এর মূল দুটি সমান হলে k? D = 0 → k² − 36 = 0 → **k = ±6**।

**উদাহরণ ৫:** মূল 3 ও 5 হলে সমীকরণ: x² − (3+5)x + 15 = **x² − 8x + 15 = 0**।

**উদাহরণ ৬:** √(x+4) = 3 → x + 4 = 9 → **x = 5** (বর্গ করার পর যাচাই করুন)।

**উদাহরণ ৭ (দুই অঙ্কের সংখ্যা):** অঙ্কদ্বয়ের যোগ 9; অঙ্ক স্থান বদল করলে সংখ্যাটি 27 কমে। সংখ্যা কত? দশক x, একক y। x + y = 9; (10x + y) − (10y + x) = 27 → 9(x − y) = 27 → x − y = 3। তাহলে x = 6, y = 3। সংখ্যা **63**।

## ১৬. অসমতা

বিস্তারিত চ্যাটে আলোচনা হয়েছে। সারসংক্ষেপ:

- ঋণাত্মক সংখ্যা দিয়ে গুণ/ভাগ করলে চিহ্ন **উল্টে যায়**।
- (x−a)(x−b) < 0 → **মাঝে**, মূল বাদ → (a, b)
- (x−a)(x−b) ≤ 0 → মাঝে, মূল সহ → \[a, b\]
- (x−a)(x−b) > 0 → **বাইরে**, মূল বাদ → (−∞, a) ∪ (b, ∞)
- (x−a)(x−b) ≥ 0 → বাইরে, মূল সহ → (−∞, a\] ∪ \[b, ∞)
- |x| < a → −a < x < a; |x| > a → x < −a অথবা x > a
- x² এর সহগ ঋণাত্মক হলে আগে −1 দিয়ে গুণ করে চিহ্ন উল্টে নিন।

## ১৬ (ক). ক্ষেত্র (ক্ষেত্রফল ও আয়তন)

**সমতলক্ষেত্র:**

- **আয়তক্ষেত্র:** ক্ষেত্রফল = l × b; পরিসীমা = 2(l + b); কর্ণ = √(l² + b²)
- **বর্গ:** ক্ষেত্রফল = a²; পরিসীমা = 4a; কর্ণ = a√2
- **ত্রিভুজ:** ½ × ভূমি × উচ্চতা
- **সামান্তরিক:** ভূমি × উচ্চতা
- **রম্বস:** ½ × d₁ × d₂ (কর্ণদ্বয়ের গুণফলের অর্ধেক)
- **ট্রাপিজিয়াম:** ½ × (সমান্তরাল বাহুদ্বয়ের যোগফল) × উচ্চতা
- **বৃত্ত:** ক্ষেত্রফল = πr²; পরিধি = 2πr

**ঘনবস্তু (আয়তন, তলের ক্ষেত্রফল):**

- **আয়তাকার ঘনবস্তু:** V = lbh; সমগ্র তল = 2(lb + bh + hl); কর্ণ = √(l² + b² + h²)
- **ঘনক:** V = a³; সমগ্র তল = 6a²; কর্ণ = a√3
- **বেলন:** V = πr²h; বক্রতল = 2πrh; সমগ্র তল = 2πr(r + h)
- **শঙ্কু:** V = ⅓πr²h; বক্রতল = πrl; তির্যক উচ্চতা l = √(r² + h²)
- **গোলক:** V = (4/3)πr³; তল = 4πr²

**উদাহরণ ১:** আয়তক্ষেত্রের দৈর্ঘ্য 12, প্রস্থ 5। ক্ষেত্রফল = **60**, কর্ণ = √169 = **13**, পরিসীমা = **34**।

**উদাহরণ ২:** বর্গের কর্ণ 10√2 হলে বাহু 10, ক্ষেত্রফল **100**।

**উদাহরণ ৩:** বর্গের বাহু 20% বাড়লে ক্ষেত্রফল? (1.2)² = 1.44, তাই **44% বাড়বে**।

**উদাহরণ ৪:** 10 মি × 8 মি মাঠের বাইরে চারদিকে 2 মি চওড়া রাস্তা। রাস্তার ক্ষেত্রফল? বড় ক্ষেত্র = 14 × 12 = 168; মাঠ = 80। রাস্তা = **88 বর্গমিটার**।

**উদাহরণ ৫:** বেলনের r = 7, h = 10 হলে আয়তন? (22/7) × 49 × 10 = **1540**।

**উদাহরণ ৬:** ঘনকের কর্ণ 6√3 হলে বাহু 6, আয়তন **216**।

## ১৭. ত্রিভুজ

**মূল তথ্য:**

- তিন কোণের সমষ্টি 180°। বহিঃকোণ = অন্তঃস্থ বিপরীত দুই কোণের যোগফল।
- যেকোনো দুই বাহুর যোগফল তৃতীয় বাহু অপেক্ষা বড়। (3, 4, 8 দিয়ে ত্রিভুজ হয় না)
- **হেরনের সূত্র:** s = (a + b + c)/2 হলে ক্ষেত্রফল = √\[s(s−a)(s−b)(s−c)\]
- **সমবাহু ত্রিভুজ (বাহু a):** ক্ষেত্রফল = (√3/4)a²; উচ্চতা = (√3/2)a
- **পিথাগোরাস:** সমকোণী ত্রিভুজে a² + b² = c² (c = অতিভুজ)
- **পিথাগোরীয় ত্রয়ী (মুখস্থ):** (3, 4, 5), (5, 12, 13), (8, 15, 17), (7, 24, 25), (9, 40, 41), (20, 21, 29)
- **বিশেষ সমকোণী:** 45°-45°-90° এ বাহুর অনুপাত 1 : 1 : √2; 30°-60°-90° এ 1 : √3 : 2
- **সদৃশ ত্রিভুজ:** ক্ষেত্রফলের অনুপাত = বাহুর অনুপাতের বর্গ
- **মধ্যমা:** তিন মধ্যমা একবিন্দুতে (ভরকেন্দ্র) 2 : 1 অনুপাতে ছেদ করে
- **সর্বসমতা:** SSS, SAS, ASA, RHS

**উদাহরণ ১:** বাহু 13, 14, 15 হলে ক্ষেত্রফল? s = 21; √(21 × 8 × 7 × 6) = √7056 = **84**।

**উদাহরণ ২:** সমবাহু ত্রিভুজের বাহু 6 হলে ক্ষেত্রফল = (√3/4) × 36 = **9√3**।

**উদাহরণ ৩:** সমকোণী ত্রিভুজের অতিভুজ 17, এক বাহু 8 হলে অপর বাহু? √(289 − 64) = √225 = **15**।

**উদাহরণ ৪:** তিন কোণের অনুপাত 2 : 3 : 4 হলে কোণ কত? 180 ÷ 9 = 20, তাই **40°, 60°, 80°**।

**উদাহরণ ৫:** দুই সদৃশ ত্রিভুজের বাহুর অনুপাত 2 : 3 হলে ক্ষেত্রফলের অনুপাত **4 : 9**।

## ১৮. চতুর্ভুজ

**মূল তথ্য:** চার কোণের সমষ্টি 360°।

- **সামান্তরিক:** বিপরীত বাহু ও কোণ সমান; কর্ণ পরস্পরকে সমদ্বিখণ্ডিত করে; ক্ষেত্রফল = ভূমি × উচ্চতা।
- **আয়ত:** সামান্তরিক + প্রতিটি কোণ 90°; **কর্ণদ্বয় সমান**।
- **রম্বস:** চার বাহু সমান; **কর্ণদ্বয় পরস্পরকে লম্বভাবে সমদ্বিখণ্ডিত করে**; ক্ষেত্রফল = ½ d₁d₂; বাহু = ½√(d₁² + d₂²)।
- **বর্গ:** চার বাহু সমান + চার কোণ সমকোণ; কর্ণদ্বয় সমান ও পরস্পর লম্ব।
- **ট্রাপিজিয়াম:** এক জোড়া বিপরীত বাহু সমান্তরাল; ক্ষেত্রফল = ½(a + b)h; মধ্যরেখা = ½(a + b)।

**বহুভুজ (n বাহুবিশিষ্ট):**

- অন্তঃকোণের সমষ্টি = (n − 2) × 180°
- বহিঃকোণের সমষ্টি = **360°** (সব ক্ষেত্রে)
- সুষম বহুভুজের প্রতিটি অন্তঃকোণ = (n − 2) × 180° ÷ n
- কর্ণের সংখ্যা = **n(n − 3)/2**

**উদাহরণ ১:** রম্বসের কর্ণ 24 ও 10 হলে ক্ষেত্রফল = **120**; বাহু = ½√(576 + 100) = ½ × 26 = **13**; পরিসীমা = **52**।

**উদাহরণ ২:** ট্রাপিজিয়ামের সমান্তরাল বাহু 8 ও 12, উচ্চতা 5 হলে ক্ষেত্রফল = ½ × 20 × 5 = **50**।

**উদাহরণ ৩:** সামান্তরিকের ভূমি 12, উচ্চতা 7 হলে ক্ষেত্রফল = **84**।

**উদাহরণ ৪:** সুষম ষড়ভুজের প্রতিটি অন্তঃকোণ = 4 × 180 ÷ 6 = **120°**; কর্ণ = 6 × 3 ÷ 2 = **9টি**।

**উদাহরণ ৫:** অষ্টভুজের অন্তঃকোণের সমষ্টি = 6 × 180 = **1080°**; কর্ণ = 8 × 5 ÷ 2 = **20টি**।

## ১৯. বৃত্ত

**সূত্র:**

- পরিধি = 2πr = πd; ক্ষেত্রফল = πr² (π ≈ 22/7 অথবা 3.1416)
- **চাপের দৈর্ঘ্য** = (θ/360) × 2πr
- **বৃত্তকলার ক্ষেত্রফল** = (θ/360) × πr²
- ব্যাসার্ধ 10% বাড়লে ক্ষেত্রফল **21%** বাড়ে (1.1² = 1.21)

**জ্যামিতির ধারণা:**

- কেন্দ্রস্থ কোণ = ২ × একই চাপের উপর বৃত্তস্থ কোণ
- অর্ধবৃত্তস্থ কোণ = 90°
- কেন্দ্র থেকে জ্যা-এর উপর লম্ব জ্যাকে সমদ্বিখণ্ডিত করে। জ্যা-এর দৈর্ঘ্য = **2√(r² − d²)** (d = কেন্দ্র থেকে দূরত্ব)
- স্পর্শক স্পর্শবিন্দুগামী ব্যাসার্ধের উপর লম্ব। বহিঃস্থ বিন্দু থেকে দুটি স্পর্শক সমান। স্পর্শকের দৈর্ঘ্য = **√(d² − r²)**
- বৃত্তস্থ চতুর্ভুজের বিপরীত কোণদ্বয় সম্পূরক (যোগফল 180°)
- সমকোণী ত্রিভুজে পরিব্যাসার্ধ = অতিভুজ ÷ 2; অন্তঃব্যাসার্ধ = (a + b − c)/2
- সাধারণ ত্রিভুজে অন্তঃব্যাসার্ধ = ক্ষেত্রফল ÷ s

**উদাহরণ ১:** r = 7 হলে পরিধি = **44**, ক্ষেত্রফল = **154**।

**উদাহরণ ২:** পরিধি 88 হলে r = 14, ক্ষেত্রফল = (22/7) × 196 = **616**।

**উদাহরণ ৩:** r = 10, θ = 90° হলে চাপ = ¼ × 2π × 10 = **5π ≈ 15.7**।

**উদাহরণ ৪:** r = 5, কেন্দ্র থেকে 3 দূরে জ্যা-এর দৈর্ঘ্য = 2√(25 − 9) = **8**।

**উদাহরণ ৫:** কেন্দ্র থেকে 13 দূরের বিন্দু থেকে r = 5 বৃত্তের স্পর্শক = √(169 − 25) = **12**।

**উদাহরণ ৬:** সমকোণী ত্রিভুজ 6, 8, 10 এর অন্তঃব্যাসার্ধ = (6 + 8 − 10)/2 = **2**, পরিব্যাসার্ধ = **5**।

## ২০. উচ্চতর গণিত

পরীক্ষাভেদে সিলেবাস আলাদা। নিচে চাকরির পরীক্ষায় বেশি আসা অংশগুলো দেওয়া হলো।

### (ক) সেট

- n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
- n উপাদানের সেটের উপসেট = 2^n; প্রকৃত উপসেট = 2^n − 1

**উদাহরণ:** 100 জনের মধ্যে 60 জন ক্রিকেট, 50 জন ফুটবল পছন্দ করে, 10 জন কোনোটিই না। উভয়ই পছন্দ করে কতজন? 90 = 60 + 50 − x → **x = 20**।

### (খ) ধারা

- **সমান্তর ধারা:** aₙ = a + (n−1)d; Sₙ = (n/2)\[2a + (n−1)d\] = (n/2)(a + l)
- **গুণোত্তর ধারা:** aₙ = ar^(n−1); Sₙ = a(rⁿ − 1)/(r − 1)
- **অসীম গুণোত্তর ধারা** (|r| < 1): S = a/(1 − r)
- 1 + 2 + … + n = n(n+1)/2; 1² + 2² + … + n² = n(n+1)(2n+1)/6; 1³ + … + n³ = \[n(n+1)/2\]²

**উদাহরণ ১:** 1 + 2 + … + 100 = 100 × 101/2 = **5050**।

**উদাহরণ ২:** 2, 5, 8, … এর ১০ম পদ = 2 + 9 × 3 = **29**; প্রথম ১০ পদের যোগফল = 5 × (2 + 29) = **155**।

**উদাহরণ ৩:** 1 + 1/2 + 1/4 + … = 1/(1 − 1/2) = **2**।

### (গ) বিন্যাস ও সমাবেশ

- **বিন্যাস (ক্রম আছে):** nPr = n!/(n−r)!
- **সমাবেশ (ক্রম নেই):** nCr = n!/\[r!(n−r)!\]; nCr = nC(n−r)
- পুনরাবৃত্ত বর্ণ থাকলে: মোট!/(পুনরাবৃত্ত!)

**উদাহরণ ১:** 5 জন থেকে 3 জনের কমিটি = 5C3 = **10**।

**উদাহরণ ২:** BANGLA এর বর্ণ দিয়ে শব্দ বিন্যাস (A দুইবার) = 6!/2! = 720/2 = **360**।

### (ঘ) সম্ভাবনা

- P(E) = অনুকূল ফল ÷ মোট ফল; P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
- ঘটনা না ঘটার সম্ভাবনা = 1 − P(E)

**উদাহরণ ১:** একটি ছক্কায় জোড় সংখ্যা আসার সম্ভাবনা = 3/6 = **1/2**।

**উদাহরণ ২:** দুটি মুদ্রা ছুড়লে অন্তত একটি হেড = 1 − 1/4 = **3/4**।

**উদাহরণ ৩:** দুটি ছক্কায় যোগফল 7 হওয়ার সম্ভাবনা = 6/36 = **1/6**।

### (ঙ) ত্রিকোণমিতি

- sin²θ + cos²θ = 1; 1 + tan²θ = sec²θ; 1 + cot²θ = cosec²θ
- tanθ = sinθ/cosθ; sin(90° − θ) = cosθ

**মান-তালিকা (মুখস্থ):**

- sin: 0°→0, 30°→1/2, 45°→1/√2, 60°→√3/2, 90°→1
- cos: 0°→1, 30°→√3/2, 45°→1/√2, 60°→1/2, 90°→0
- tan: 0°→0, 30°→1/√3, 45°→1, 60°→√3, 90°→অসংজ্ঞায়িত

**উদাহরণ ১:** sin30° cos60° + cos30° sin60° = 1/4 + 3/4 = **1**।

**উদাহরণ ২ (উচ্চতা-দূরত্ব):** গাছের গোড়া থেকে 20 মি দূরে দাঁড়িয়ে চূড়ার উন্নতি কোণ 45°। গাছের উচ্চতা = 20 × tan45° = **20 মি**।

### (চ) স্থানাঙ্ক জ্যামিতি

- দূরত্ব = √\[(x₂ − x₁)² + (y₂ − y₁)²\]
- মধ্যবিন্দু = ((x₁ + x₂)/2, (y₁ + y₂)/2)

**উদাহরণ:** (1, 2) ও (4, 6) এর দূরত্ব = √(9 + 16) = **5**; মধ্যবিন্দু = **(2.5, 4)**।

### (ছ) ক্যালকুলাস (প্রাথমিক)

- d/dx (xⁿ) = n·xⁿ⁻¹; ∫ xⁿ dx = xⁿ⁺¹/(n+1) + C

**উদাহরণ:** d/dx (3x² + 5x) = **6x + 5**; ∫ 2x dx = **x² + C**।
