# বাংলা ব্যাকরণ: ১ (MCQ ও লিখিত)

টপিক: সন্ধি · শব্দ · বাগধারা · এক কথায় প্রকাশ · সমাস

## ১. সন্ধি

সন্ধি তিন প্রকার: **স্বরসন্ধি**, **ব্যঞ্জনসন্ধি**, **বিসর্গ সন্ধি**।

### স্বরসন্ধির মূল নিয়ম (স্বর + স্বর)

| নিয়ম            | ফল        | উদাহরণ                                    |
| ---------------- | --------- | ----------------------------------------- |
| অ/আ + অ/আ        | **আ**     | হিম+অচল = হিমাচল, বিদ্যা+আলয় = বিদ্যালয় |
| ই/ঈ + ই/ঈ        | **ঈ**     | অতি+ইব = অতীব, গিরি+ঈশ = গিরীশ            |
| অ/আ + ই/ঈ        | **এ**     | নর+ইন্দ্র = নরেন্দ্র                      |
| অ/আ + উ/ঊ        | **ও**     | সূর্য+উদয় = সূর্যোদয়                    |
| অ/আ + ঋ          | **অর্**   | সপ্ত+ঋষি = সপ্তর্ষি                       |
| অ/আ + এ/ঐ        | **ঐ**     | সর্ব+এব = সর্বৈব                          |
| অ/আ + ও/ঔ        | **ঔ**     | বন+ওষধি = বনৌষধি                          |
| ই/ঈ + ভিন্ন স্বর | **য-ফলা** | অতি+অন্ত = অত্যন্ত                        |
| উ/ঊ + ভিন্ন স্বর | **ব-ফলা** | সু+আগত = স্বাগত                           |

**এ, ঐ, ও, ঔ-এর পর স্বর থাকলে:**

- এ = অয়: নে+অন = নয়ন
- ঐ = আয়: নৈ+ক = নায়ক
- ও = অব: পো+অন = পবন
- ঔ = আব: নৌ+ইক = নাবিক

### ব্যঞ্জনসন্ধি

- উৎ+চারণ = উচ্চারণ
- সৎ+জন = সজ্জন
- উৎ+লাস = উল্লাস
- উৎ+শ্বাস = উচ্ছ্বাস
- সম্+গীত = সংগীত
- সম্+সার = সংসার

### বিসর্গ সন্ধি

- নিঃ+পাপ = নিষ্পাপ
- দুঃ+কর = দুষ্কর
- নিঃ+চয় = নিশ্চয়
- তপঃ+বন = তপোবন
- মনঃ+কষ্ট = মনোকষ্ট

### নিপাতনে সিদ্ধ (মুখস্থ করতে হয়)

আশীর্বাদ, আশ্চর্য, গবাক্ষ, কুলটা, মনীষা, বনস্পতি, বৃহস্পতি, পতঞ্জলি

> **MCQ ট্রিক:** শব্দটা ভেঙে দেখো, আগের শব্দের শেষ ধ্বনি আর পরের শব্দের প্রথম ধ্বনি কী। সেটা কোন নিয়মে পড়ে, তা মিলিয়ে নাও।

## ২. শব্দ

প্রশ্ন সাধারণত আসে এই ধরনের:

- **উৎস অনুযায়ী শব্দ**
  - তৎসম (সংস্কৃত থেকে অবিকৃত): সূর্য, চন্দ্র
  - অর্ধ-তৎসম (কিছুটা বিকৃত): জ্যোছনা, গিন্নি
  - তদ্ভব (সংস্কৃত থেকে বিবর্তিত): চাঁদ, সোনা
  - দেশি (বাংলার নিজস্ব): ঢেঁকি, কুলা
  - বিদেশি: আরবি-ফারসি (কলম, আদালত), ইংরেজি (টেবিল, স্কুল), পর্তুগিজ (বালতি, আলমারি)
- সমার্থক শব্দ (যেমন সূর্য = রবি, ভানু, দিবাকর) এবং বিপরীত শব্দ
- এক শব্দের একাধিক অর্থ
- শুদ্ধ বানান

## ৪. এক কথায় প্রকাশ

| বাক্যাংশ                    | এক কথায়       |
| --------------------------- | -------------- |
| যা দমন করা যায় না          | অদম্য          |
| যা ভেদ করা যায় না          | অভেদ্য         |
| যার তুলনা নেই               | অনুপম          |
| যা আগে কখনো হয়নি           | অভূতপূর্ব      |
| যা সহজে পাওয়া যায় না      | দুষ্প্রাপ্য    |
| যার স্ত্রী মারা গেছে        | বিপত্নীক       |
| যে বেশি কথা বলে             | বাচাল          |
| যার আদি নেই                 | অনাদি          |
| সমুদ্র থেকে হিমালয় পর্যন্ত | আসমুদ্র হিমাচল |
| ভবিষ্যৎ না ভেবে কাজ করে যে  | অবিমৃশ্যকারী   |

> **ট্রিক:** উপসর্গ দেখে অর্থ আন্দাজ করো। অ-/অন-/নির্-/দুর্ মানে সাধারণত "না" বা "খারাপ"।

## ৫. সমাস

সমাসের মূল কাজ **ব্যাসবাক্য** (ভেঙে লেখা) করা।

| সমাস           | চেনার উপায়                           | উদাহরণ                    |
| -------------- | ------------------------------------- | ------------------------- |
| **দ্বন্দ্ব**   | দুই পদই প্রধান, মাঝে "ও/এবং"          | মা-বাবা = মা ও বাবা       |
| **কর্মধারয়**  | বিশেষণ + বিশেষ্য, বা উপমা             | নীলাকাশ = নীল যে আকাশ     |
| **তৎপুরুষ**    | পরপদ প্রধান, মাঝের বিভক্তি লোপ        | রাজপুত্র = রাজার পুত্র    |
| **বহুব্রীহি**  | সমস্ত পদ অন্য কিছুকে বোঝায়           | দশানন = দশ আনন যার (রাবণ) |
| **দ্বিগু**     | পূর্বপদ সংখ্যাবাচক, সমষ্টি বোঝায়     | ত্রিফলা = তিন ফলের সমাহার |
| **অব্যয়ীভাব** | পূর্বপদ অব্যয়, অব্যয়ের অর্থই প্রধান | প্রতিদিন = দিন দিন        |

> **ট্রিক:** কোন পদ প্রধান তা আগে ঠিক করো। দুটো পদই প্রধান হলে দ্বন্দ্ব। পরের পদ প্রধান হলে তৎপুরুষ/কর্মধারয়। তৃতীয় কিছু বোঝালে বহুব্রীহি।
